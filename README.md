Payroll Pros is our SDEV 120 Python payroll project that takes employee information, handles the calculations, and produces the final payroll results.

What it does:

Collects info for 10 employees
Validates employee input
Calculates regular + overtime pay
Calculates 5.6% state + 7.9% federal tax
Calculates post-tax pay
Displays and saves payroll results

Project Files:

(main.py) - Runs everything
(input.py) - Collects + validates employee info
(calculations.py) -Handles payroll math
(output.py) - Displays + saves results
(payroll_results.txt) - Sample generated results

Run it:
python main.py
